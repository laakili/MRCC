Guide d'utilisation - MRCC Maroc
📊 Modèle de calcul IAMSAR

Le système utilise les équations standardisées de l'IAMSAR (International Aeronautical and Maritime Search and Rescue Manual) pour calculer la dérive :

Type d'objet Coeff. vent Angle dérive Description
Personne 3% 2.0° Personne avec gilet
Radeau 4% 1.5° Radeau gonflable
Canot 2% 1.0° Canot rigide
Bateau pêche 1% 0.8° < 15 mètres
🧮 Formules de calcul
Vtotale = Vcourant + (Vvent × Cvent)
θeff = θcourant + (Leeway × État mer)
Distance = ∫ V(t) dt
🎯 Instructions détaillées
  1. Position initiale : Saisissez les coordonnées du dernier contact
  2. Courants : Utilisez les données des bouées ou des modèles
  3. Vent : Données météo en temps réel ou prévisions
  4. Type d'objet : Sélectionnez l'objet le plus proche
  5. État de mer : Échelle de Douglas (observation visuelle)
  6. Durée : Adaptez à la situation (max 72h recommandé)
⚠️ Facteurs d'incertitude
  • Courants : ±20%
  • Vent : ±30%
  • Position initiale : ±10%
  • Angle de dérive : ±15%
Note importante : Les résultats sont des estimations. Toujours prévoir une marge d'incertitude et confirmer par des observations visuelles.
